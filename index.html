FEATURED ACADEMIC PROJECT

Student Gap Analyser

An intelligent academic evaluation system designed to detect, diagnose, and bridge conceptual learning gaps among students through automated analysis and personalized remediation.

Academic Initiative Python • FastAPI • Web Technologies Core Developer

Transforming Student Assessment into Actionable Learning Roadmaps

Traditional exams only provide aggregate marks, leaving students unaware of which specific concepts or subtopics they failed to grasp. Student Gap Analyser addresses this by tracking granular question-level responses, mapping them to taxonomy competencies, and generating automated diagnostic heatmaps for students and instructors.

01

Diagnostic Assessment Engine

Evaluates subject quizzes across foundational and applied topics with weighted difficulty tags.

02

Concept Gap Matrix

Computes gap percentages by topic (e.g., Recursion, Memory, API routing) to pinpoint friction areas.

03

FastAPI Backend Service

High-speed asynchronous REST endpoints to submit assessments, retrieve analytics, and manage records.

04

Personalized Remedial Path

Generates targeted practice recommendations, curated articles, and milestone practice challenges.
